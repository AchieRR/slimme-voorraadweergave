# Slimme voorraadweergave

MBO niveau 4-schoolproject voor een camping en appartementenverhuur.

Het systeem krijgt uiteindelijk:

- een publieke, e-inkvriendelijke voorraadpagina voor gasten;
- een mobiele beheeromgeving voor medewerkers;
- een beveiligde backend/API;
- een database waarin de voorraad blijvend wordt opgeslagen;
- authenticatie voor minimaal twee medewerkers.

## Werkwijze

De student typt de applicatiecode zelf. Codex begeleidt het project in kleine stappen, legt iedere stap uit en controleert de code en testresultaten.

De technische keuzes worden pas definitief gemaakt nadat ze zijn onderzocht en onderbouwd.
